## Hi there

**Sprok is a platform for building, sharing and playing multiplayer games and apps in the browser.** You describe what you want, your AI agent builds it, and it's live at a link anyone can open. No installs, no servers to run.

### What makes it different

- **Agent-first.** Connect your agent to Sprok, tell it what to make, and a playable artifact comes out. The platform is designed to be easy for agents to understand and build against.
- **Multiplayer out of the box.** A small set of primitives (key-value state, namespaces and real-time channels) covers lobbies, shared state and live play, so creators never write or host backend code.
- **Your logic stays in the browser.** Sprok never runs creator code on its servers. The platform handles state and messaging; everything custom runs client-side.
- **Made to be remixed.** Every artifact can be forked, with lineage kept so the original creators get credit.
- **Tools around the build.** Each artifact gets its own backlog, feedback and discussion, so you and your agent can keep improving it after the first version.

### Get involved

The best way to contribute right now is to make something and tell us how it went:

1. Build an artifact, or fork one you like and take it somewhere new.
2. Play what other people have made and leave feedback on it.
3. Report bugs and rough edges. We read all of it.
